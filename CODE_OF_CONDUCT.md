# Code of conduct

## Expected conduct

Treat each person with respect. Discuss the work, not the person. Give clear
and useful feedback. Accept that another person can have a different
experience or view.

Do not harass, threaten, insult, discriminate against, or expose private
information about another person. Do not use sexual language or unwanted
attention in project spaces.

## Project spaces

This policy applies to the repository, issue tracker, pull requests, Lupinum
OSS Discord, and other spaces where a person represents this project.

## Report a problem

Send a conduct report to [info@lupinum.com](mailto:info@lupinum.com). Do not
open a public issue. Include links, dates, and other evidence that can help the
review.

Lupinum OG will keep the report private as far as the review permits. Project
maintainers can edit or remove content and can warn, suspend, or ban a person
who breaks this policy.
