Change to the first stable version: 1.0.0 leaves the `beta` prerelease line

The components, style keys, module options, error codes and test helpers of this release are the stable contract. A change that breaks them now comes only in a new major version.

Migration: an application on `0.4.0-beta.6` follows the [upgrade guide](https://nuxt-pdf.lupinum.com/docs/upgrade-guide); every change it lists is in this release.
