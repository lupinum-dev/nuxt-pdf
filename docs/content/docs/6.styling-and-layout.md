Style a template with classes in a plain `<style>` block. Nuxt PDF compiles the
block to typed PDF style objects at build time. It is a subset of CSS with
flex layout; no browser stylesheet or cascade is involved.

## Style with classes

Set `class` on primitives and define the classes in the `<style>` block of the
same file:

```vue [pdfs/invoice.vue]
<script setup lang="ts">
definePdf({ title: 'Invoice' })
</script>

<template>
  <PdfDocument language="en">
    <PdfPage size="A4" class="page">
      <PdfView class="total-row">
        <PdfText class="total-label">Invoice total</PdfText>
        <PdfText>USD 1,250.00</PdfText>
      </PdfView>
    </PdfPage>
  </PdfDocument>
</template>

<style>
:root {
  --muted: #6A756D;
  --page-margin: 48pt;
}
.page {
  padding: 44pt var(--page-margin);
  font-size: 9pt;
}
.total-row {
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  padding: 12pt;
  background-color: #F1F4F1;
}
.total-label {
  color: var(--muted);
}
</style>
```

- Use class selectors, such as `.total-row`, `.row.total`, or `.total .cell`.
  Other selectors fail the build. Write a plain `<style>` block, without
  `scoped`, `module`, or `lang`.
- Write CSS property names. Shorthands such as `padding`, `margin`, `border`,
  and `flex` expand to PDF style keys.
- Declare a value that repeats as a variable in `:root`, and read it with
  `var(--name)`. Variables are local to the file. Share them between files
  with `@import './theme.css'`, or read a script value with `v-bind()`.
- Use `:class` to switch between defined classes:
  `:class="{ 'total-row-strong': isTotal }"`.

An invalid value or an unknown static class name fails the build with the file, line, and
column. The [style reference]($docs.styles#the-style-block) lists the accepted
CSS, the shorthands, the class order, and every build error.

## Core rules

- Unitless numbers are PDF points.
- Length strings accept `pt`, `px`, `in`, `mm`, `cm`, `rem`, `vh`, and `vw`
  where the property supports them. See
  [Values and units]($docs.styles#values-and-units).
- The default flex direction is `column`.
- Font family, size, weight, style, letter spacing, line height, text
  decoration, text transform, `hyphens`, color, opacity, and text alignment can
  inherit through the document tree. Set other layout explicitly.
- Text inside `PdfSvg` does not inherit from outside the SVG. It takes only the
  presentation props of the SVG elements around it and its own style, and
  starts from Helvetica 18 pt. Set `fontFamily` and `fontSize` on each
  `PdfText` in the SVG.

## Use style objects for dynamic values

Use `:style` for a value that comes from data, such as a computed width or a
color from props. A style object uses camelCase keys, and unitless numbers are
points. `style` applies after all classes, so it wins. The render checks each
value and rejects only a value that the engine cannot read correctly, such as
`fontSize: '1.2em'` or `color: false`, with `PDF_TREE_INVALID`. A style object
accepts some forms that the `<style>` block rejects, such as `margin: '4pt 8pt'`
or `width: 'auto'`; see
[Style object values]($docs.styles#style-object-values). A key whose value is
`null` or `undefined` is left out:

```vue
<PdfView class="bar" :style="{ width: `${share * 100}%` }" />
```

## Type shared styles

Use `satisfies PdfStyle` so TypeScript checks keys and values of a style object
in a script without widening the object:

```ts [pdfs/components/theme.ts]
import type { PdfStyle } from '@lupinum/nuxt-pdf'

export const eyebrow = {
  color: '#566159',
  fontSize: 7,
  letterSpacing: 1.4,
  textTransform: 'uppercase',
} satisfies PdfStyle
```

Style arrays merge left to right. Nested arrays are flattened, and `false`,
`null`, and `undefined` entries are ignored:

```vue
<PdfText :style="[base, isTotal && total]">
  {{ amount }}
</PdfText>
```

## Share geometry once

When a table header and its rows must align, use `PdfTable`. It holds the
column widths once, and every `PdfTableHeader` and `PdfTableRow` takes its
columns from it:

```vue
<PdfTable :columns="['28pt', 1, '86pt']">
  <PdfTableHeader class="line-header">
    <PdfTableCell>#</PdfTableCell>
    <PdfTableCell>Description</PdfTableCell>
    <PdfTableCell align="right">Amount</PdfTableCell>
  </PdfTableHeader>
  <PdfTableRow v-for="(line, index) in lines" :key="line.id">
    <PdfTableCell>{{ index + 1 }}</PdfTableCell>
    <PdfTableCell>{{ line.description }}</PdfTableCell>
    <PdfTableCell align="right">{{ line.amount }}</PdfTableCell>
  </PdfTableRow>
</PdfTable>
```

A number is a share of the free width; a string such as `'28pt'` or `'50%'` is
a fixed width, and `'auto'` is as wide as the widest cell of the column (see
[automatic column widths]($docs.tables#automatic-column-widths)). The [recipe guide]($docs.recipes) shows tables, totals,
running heads, and page-break patterns.
