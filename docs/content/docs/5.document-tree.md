Nuxt PDF renders a closed tree of PDF primitives. It does not render HTML or DOM
components.

## Root and page structure

Each template has one `PdfDocument` root and at least one `PdfPage`:

```vue
<PdfDocument>
  <PdfPage>
    <PdfView>
      <PdfText>Quarterly report</PdfText>
    </PdfView>
  </PdfPage>
</PdfDocument>
```

The main primitives are:

| Primitive | Role |
| --- | --- |
| `PdfDocument` | Document root and metadata |
| `PdfPage` | One fixed or wrapping page |
| `PdfView` | Flex layout container |
| `PdfText` | Text content and inline text runs |
| `PdfImage` | PNG or JPEG image |
| `PdfLink` | External or internal link |
| `PdfNote` | PDF note annotation |
| `PdfTable` | Table with fixed columns and a repeated header |
| `PdfPageNumber`, `PdfPageCount`, `PdfPageRef` | Page numbers inside `PdfText` |
| `PdfAttachment` | File embedded in the PDF |

The [primitive reference]($docs.primitives) lists the closed prop and
nesting surface. The [SVG guide]($docs.svg-graphics) covers vector
graphics.

::warning{icon="lucide:triangle-alert"}
Put all visible text inside `PdfText`. Text placed directly under `PdfPage` or
`PdfView` fails with `PDF_TREE_INVALID`; it is not discarded.
::

## Vue composition

Use local Vue components, typed props, slots, `v-if`, and keyed `v-for`. Keep
components owned by one document under a document-specific directory:

```vue [pdfs/components/invoice/InvoiceLine.vue]
<script setup lang="ts">
defineProps<{ label: string; amount: string }>()
</script>

<template>
  <PdfView class="line">
    <PdfText>{{ label }}</PdfText>
    <PdfText>{{ amount }}</PdfText>
  </PdfView>
</template>

<style>
.line {
  flex-direction: row;
  justify-content: space-between;
}
</style>
```

Import the component from the template. Nuxt app plugins, global components,
directives, and app-level provides do not enter the PDF tree.

## Dynamic page text

Put `PdfPageNumber` and `PdfPageCount` inside a `PdfText`. Nuxt PDF prints the
numbers after layout:

```vue
<PdfText fixed>
  Page <PdfPageNumber /> of <PdfPageCount />
</PdfText>
```

`fixed` repeats the node on each page of its parent. A `PdfText` inside a
`fixed` `PdfView` repeats with it and needs no `fixed` of its own. A page token
cannot go into a computed string; put it after the template expression (see
[page tokens]($docs.primitives#page-tokens)). Add `pages="first"` or
`pages="continuation"` to a `fixed` node to show it only on the first page or
on every page after the first. Place a running head absolutely in the page padding, so it takes no
space in the flow (see [fixed content and pages]($docs.primitives#fixed-content-and-pages)).
For a table of contents, use
[`PdfPageRef`]($docs.contents-links-bookmarks).

Invalid nesting, unknown primitive props, DOM attributes, `Teleport`, and
`v-show` fail instead of producing incomplete PDF content.
