PDF components are ordinary local Vue components whose rendered roots are Nuxt
PDF primitives. Extract a component when it owns a meaningful document section
or repeats in more than one place.

## Keep ownership visible

Put document-specific components next to their document family:

```bash [Application files]
pdfs/
├── invoice.vue
└── components/
    └── invoice/
        ├── InvoiceAddress.vue
        └── InvoiceLine.vue
```

Move a component to `pdfs/components/` only when several templates use it. This
keeps invoice-specific decisions out of a generic component API.

## Pass typed document data

```vue [pdfs/components/invoice/InvoiceAddress.vue]
<script setup lang="ts">
defineProps<{
  label: string
  lines: string[]
}>()
</script>

<template>
  <PdfView>
    <PdfText class="address-label">
      {{ label }}
    </PdfText>
    <PdfText v-for="line in lines" :key="line">
      {{ line }}
    </PdfText>
  </PdfView>
</template>

<style>
.address-label {
  margin-bottom: 4pt;
  font-size: 8pt;
}
</style>
```

Import it directly in the template. Use keyed `v-for`, slots, and `v-if` as you
would in another Vue component. Do not pass DOM attributes such as `aria-*`;
the PDF tree has no DOM.

## Style components with classes

A component uses the classes of its own `<style>` block. A class that the
parent sets on a local component uses the parent's rules and applies to the
root element of that component:

```vue [pdfs/invoice.vue (excerpt)]
<template>
  <InvoiceAddress class="party" label="Bill to" :lines="customer.address" />
</template>

<style>
.party {
  width: 50%;
}
</style>
```

The class falls through as any Vue attribute does. A component with several
root elements fails the render: give it one root element, or put
`v-bind="$attrs"` on one element. A component with `inheritAttrs: false`
drops the class unless it binds `$attrs`.

Variables are local to one file. When two files need the same value, declare
the variable in both `<style>` blocks, or pass the value as a prop.

## Share table geometry

Set the column widths once on `PdfTable`. A row component renders a
`PdfTableRow` and takes its columns from the table that contains it:

```vue [pdfs/components/invoice/InvoiceLine.vue]
<script setup lang="ts">
defineProps<{ description: string; amount: string }>()
</script>

<template>
  <PdfTableRow class="line">
    <PdfTableCell>{{ description }}</PdfTableCell>
    <PdfTableCell align="right">{{ amount }}</PdfTableCell>
  </PdfTableRow>
</template>

<style>
.line {
  padding-vertical: 10pt;
  border-bottom-width: 1pt;
  border-bottom-color: #DDE3DE;
}
</style>
```

The header and body then cannot drift apart. The
[invoice recipe]($docs.recipes#invoice-table-with-a-repeated-header) shows the
table.

The [production recipes]($docs.recipes) show address blocks, totals, running
heads, and table-of-contents patterns.
