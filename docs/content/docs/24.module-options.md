Set module options under `pdf` in `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-pdf'],
  pdf: {
    fonts: [],
    limits: {},
    remote: undefined,
  },
})
```

| Option | Type | Default | Behavior |
| --- | --- | --- | --- |
| `fonts` | `PdfFontDeclaration[]` | `[]` | Registers local TTF, OTF, or WOFF2 faces from `pdfs/fonts`. |
| `remote` | `RemoteAssetOptions` | `undefined` | Enables allowlisted HTTPS image requests. No remote request is admitted when absent. |
| `limits` | `PdfLimitsOptions` | All documented defaults | Overrides individual fields of the render budget. See [pdf.limits](#pdflimits). |

Unknown keys in `pdf`, `pdf.limits` and `pdf.remote` fail during module setup
with a `TypeError` that names the key.

## pdf.fonts

Each entry registers one font face:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  pdf: {
    fonts: [
      {
        family: 'Invoice Sans',
        src: 'InvoiceSans-Regular.ttf',
        fontStyle: 'normal',
        fontWeight: 400,
      },
    ],
  },
})
```

| Field | Type | Required | Default | Behavior |
| --- | --- | --- | --- | --- |
| `family` | `string` | Yes | Required | Family used by the `fontFamily` style property. |
| `src` | `string` | Yes | Required | TTF, OTF, or WOFF2 path relative to `pdfs/fonts`. |
| `fontWeight` | `number \| PdfFontWeightName` | No | `400` | Numeric or named weight. |
| `fontStyle` | `'normal' \| 'italic' \| 'oblique'` | No | `'normal'` | Face style. |

Register each weight and style used by a document. Invalid declarations and
font files throw `TypeError` during module setup. See
[Add images and fonts]($docs.images-and-fonts).

## pdf.remote

`remote` admits HTTPS images whose URL starts with an allowed prefix:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  pdf: {
    remote: {
      allow: ['https://cdn.example.com/brand/'],
      timeoutMs: 10_000,
    },
  },
})
```

| Field | Type | Required | Default | Behavior |
| --- | --- | --- | --- | --- |
| `allow` | `string[]` | Yes | Required | Non-empty list of exact `https://host/path/` prefixes. |
| `timeoutMs` | `number` | No | `10_000` | Timeout for each request or redirect hop, a whole number from 1 to 2,147,483,647 ms. The remaining render time also bounds it. |

Allowlist prefixes require a trailing slash. They cannot contain credentials,
queries, fragments, wildcards, or a non-HTTPS scheme. The
[remote-image guide]($docs.remote-images) defines request and redirect
behavior.

## pdf.limits

`limits` overrides fields of the budget that every render must stay inside:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  pdf: {
    limits: {
      timeoutMs: 10_000,
      maxPages: 200,
    },
  },
})
```

| Field | Default | Bounds |
| --- | --- | --- |
| `timeoutMs` | `30_000` | Whole render time in milliseconds, including the wait for a render worker. |
| `markdownTimeoutMs` | `5_000` | Whole time of one `parseRichTextMarkdown` call in milliseconds, including the wait for a render worker. |
| `maxPages` | `2_000` | Laid-out pages. |
| `maxNodes` | `50_000` | Mounted tree nodes. |
| `maxTotalImageBytes` | `33_554_432` (32 MiB) | Encoded image bytes of one render, summed over all images. |
| `maxTotalImagePixels` | `100_000_000` | Decoded image pixels of one render, summed over all images. |
| `maxRemoteRequests` | `32` | Requests of one render to allowlisted remote hosts. |
| `maxTotalAttachmentBytes` | `33_554_432` (32 MiB) | Bytes of all `PdfAttachment` files and the `PdfFacturX` XML of one render. |

Every value must be a whole number from 1. `timeoutMs` and
`markdownTimeoutMs` go up to 2,147,483,647 ms (about 24.8 days), the longest
wait a Node timer allows; the other limits go up to `Number.MAX_SAFE_INTEGER`.
There is no value for "no limit". An unknown key or a value outside the range
throws `TypeError` during module setup; the message names the option and the
range. The
[errors and limits reference]($docs.errors-and-limits) names the error of each
limit.

## Exported types

Import these types from `@lupinum/nuxt-pdf`:

| Export | Describes |
| --- | --- |
| `ModuleOptions` | Complete `pdf` module options. |
| `PdfFontDeclaration` | One registered font face. |
| `PdfFontStyle` | Accepted font styles. |
| `PdfFontWeight` | Numeric or named font weight. |
| `PdfFontWeightName` | Accepted named font weights. |
| `RemoteAssetOptions` | Remote image allowlist and timeout. |
| `PdfLimitsOptions` | Optional render-limit overrides. |
