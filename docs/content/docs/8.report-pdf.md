This guide builds a five-page sales report. It has a cover, a contents page
that prints the page where each section starts, a summary with key figures,
and a table that continues over two pages with its header repeated. The PDF
also gets bookmarks, so readers can jump between sections in their PDF viewer.

![The report that this guide builds](/showcase/guide-report.webp)

The example uses only built-in fonts. It assumes that you know how a template
and a server route work together. If not, start with
[Generate an invoice PDF]($docs.invoice-pdf).

## Define the report data

The sample data covers three years by month. That is 36 table rows, enough to
continue onto a second page.

```ts [shared/report.ts]
export interface MonthRow {
  month: string
  orders: number
  revenue: number
}

export interface Report {
  title: string
  period: string
  company: string
  summary: string
  kpis: { label: string, value: string }[]
  months: MonthRow[]
}

const monthNames = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec']

export const sampleReport: Report = {
  title: 'Sales report',
  period: '2023 to 2025',
  company: 'Acme Studio',
  summary: 'Orders grew every year. The table lists every month of the period, so it runs over more than one page.',
  kpis: [
    { label: 'Orders', value: '14,820' },
    { label: 'Revenue', value: '$2.4M' },
    { label: 'Average order', value: '$162' },
  ],
  months: [2023, 2024, 2025].flatMap((year, y) =>
    monthNames.map((name, m) => ({
      month: `${name} ${year}`,
      orders: 300 + y * 60 + m * 8,
      revenue: (300 + y * 60 + m * 8) * 162,
    })),
  ),
}
```

## Write the template

Create `pdfs/report.vue`. Each `PdfPage` starts on a new page. A page with more
content than fits continues onto as many pages as it needs.

```vue [pdfs/report.vue]
<script setup lang="ts">
import type { Report } from '../shared/report'
import { sampleReport } from '../shared/report'

const props = defineProps<{ report: Report }>()

definePdf<{ report: Report }>({
  title: ({ report }) => `${report.title} ${report.period}`,
  filename: ({ report }) => `${report.title.toLowerCase().replaceAll(' ', '-')}.pdf`,
  language: 'en-US',
  sampleData: { report: sampleReport },
})

const report = props.report
const sections = [
  { id: 'summary', title: 'Summary' },
  { id: 'monthly', title: 'Orders by month' },
]

const ink = '#09090B'
const muted = '#71717A'
const border = '#E4E4E7'
const page = { color: ink, fontSize: 10, paddingBottom: 64, paddingHorizontal: 48, paddingTop: 48 }
const footer = { bottom: 28, color: muted, fontSize: 8, left: 48, position: 'absolute', right: 48 } as const
const usd = new Intl.NumberFormat('en-US', { currency: 'USD', maximumFractionDigits: 0, style: 'currency' })
</script>

<template>
  <PdfDocument>
    <PdfPage size="A4" :style="{ ...page, justifyContent: 'flex-end' }">
      <PdfView :style="{ alignSelf: 'flex-start', borderColor: border, borderRadius: 999, borderWidth: 1, paddingHorizontal: 8, paddingVertical: 3 }">
        <PdfText :style="{ fontSize: 8 }">{{ report.company }}</PdfText>
      </PdfView>
      <PdfText :style="{ fontSize: 40, fontWeight: 700, marginTop: 14 }">{{ report.title }}</PdfText>
      <PdfText :style="{ borderBottomColor: border, borderBottomWidth: 1, color: muted, fontSize: 16, marginBottom: 96, marginTop: 6, paddingBottom: 24 }">{{ report.period }}</PdfText>
    </PdfPage>

    <PdfPage size="A4" :style="page">
      <PdfText :style="{ fontSize: 20, fontWeight: 700, marginBottom: 20 }">Contents</PdfText>
      <PdfLink
        v-for="section in sections"
        :key="section.id"
        :href="`#${section.id}`"
        :style="{ borderBottomColor: border, borderBottomWidth: 1, color: ink, flexDirection: 'row', justifyContent: 'space-between', paddingVertical: 8, textDecoration: 'none' }"
      >
        <PdfText>{{ section.title }}</PdfText>
        <PdfText><PdfPageRef :to="section.id" /></PdfText>
      </PdfLink>
    </PdfPage>

    <PdfPage size="A4" :style="page">
      <PdfView id="summary" bookmark="Summary">
        <PdfText :style="{ fontSize: 20, fontWeight: 700 }">Summary</PdfText>
        <PdfText :style="{ color: muted, lineHeight: 1.5, marginTop: 8, width: 380 }">{{ report.summary }}</PdfText>
        <PdfView :style="{ flexDirection: 'row', marginTop: 24 }">
          <PdfView
            v-for="kpi in report.kpis"
            :key="kpi.label"
            :style="{ borderColor: border, borderRadius: 8, borderWidth: 1, marginRight: 12, padding: 14, width: 150 }"
          >
            <PdfText :style="{ color: muted, fontSize: 8 }">{{ kpi.label }}</PdfText>
            <PdfText :style="{ fontSize: 20, fontWeight: 700, marginTop: 6 }">{{ kpi.value }}</PdfText>
          </PdfView>
        </PdfView>
      </PdfView>
      <PdfText fixed :style="footer">{{ report.title }} · Page <PdfPageNumber /> of <PdfPageCount /></PdfText>
    </PdfPage>

    <PdfPage size="A4" :style="page">
      <PdfView id="monthly" bookmark="Orders by month">
        <PdfText :style="{ fontSize: 14, fontWeight: 700, marginBottom: 14 }">Orders by month</PdfText>
        <PdfTable :columns="[1, '100pt', '120pt']">
          <PdfTableHeader :style="{ borderBottomColor: border, borderBottomWidth: 1, color: muted, fontSize: 8, paddingBottom: 6 }">
            <PdfTableCell>Month</PdfTableCell>
            <PdfTableCell align="right">Orders</PdfTableCell>
            <PdfTableCell align="right">Revenue</PdfTableCell>
          </PdfTableHeader>
          <PdfTableRow
            v-for="row in report.months"
            :key="row.month"
            :style="{ borderBottomColor: border, borderBottomWidth: 1, paddingVertical: 6 }"
          >
            <PdfTableCell>{{ row.month }}</PdfTableCell>
            <PdfTableCell align="right">{{ row.orders.toLocaleString('en-US') }}</PdfTableCell>
            <PdfTableCell align="right">{{ usd.format(row.revenue) }}</PdfTableCell>
          </PdfTableRow>
        </PdfTable>
      </PdfView>
      <PdfText fixed :style="footer">{{ report.title }} · Page <PdfPageNumber /> of <PdfPageCount /></PdfText>
    </PdfPage>
  </PdfDocument>
</template>
```

Open `http://localhost:3000/_pdf/report` in development to check the result
with the sample data.

## Print real page numbers in the contents

`<PdfPageRef :to="id" />` prints the page on which the element with that `id`
starts. The contents page has one for `summary` and one for `monthly`, and
each section sets the matching `id`:

```vue
<PdfView id="monthly" bookmark="Orders by month">
  <!-- the table -->
</PdfView>
```

Nuxt PDF lays the document out again until the page numbers stop changing,
usually twice. The template itself renders once. Each `PdfLink` with
`href="#monthly"` also makes the contents entry clickable. A `to` that matches
no `id` fails the render, so a renamed section cannot leave a wrong number.

[Add links, bookmarks, and a table of contents]($docs.contents-links-bookmarks)
explains the passes and their limit.

## Repeat the table header on every page

`PdfTable` lays out the rows, and its `PdfTableHeader` repeats at the top of
every page that the table reaches. `columns` sets the widths once for the
header and every row: `1` takes the free width, and `'100pt'` and `'120pt'`
are fixed.

A `PdfTableRow` does not split across pages, so a page break falls between
rows, never through one. The table also never ends a page with only its
header. See [Tables]($docs.tables) for spans, automatic column widths and the
cell rules.

## Add page numbers in the footer

The footer is a `fixed` `PdfText` with the page tokens `PdfPageNumber` and
`PdfPageCount`. A fixed node repeats on every page that its `PdfPage`
produces, and each copy prints its own page number:

```vue
<PdfText fixed :style="footer">
  {{ report.title }} · Page <PdfPageNumber /> of <PdfPageCount />
</PdfText>
```

The cover and the contents page have no footer, because the template does not
add one there. The page count still includes them.

## Add bookmarks

The `bookmark` prop on a view adds an entry to the PDF outline. PDF viewers
show the outline as a sidebar. This report gets two entries: "Summary" and
"Orders by month".

## Render the report from a route

Serve the report the same way as any other template:

```ts [server/api/reports/sales.get.ts]
import { pdf } from '#pdf'

export default defineEventHandler(async (event) => {
  const report = await loadSalesReport(event)
  const result = await pdf.report.render({ report })
  return result.response({ disposition: 'inline' })
})
```

`loadSalesReport` stands for your own function in `server/utils/` that builds
the report data and checks access.

## Keep large reports fast

A report with hundreds of rows takes longer to render than an invoice. Check
the render time in `result.diagnostics.durationMs`. When a report takes more
than a few seconds, render it in a background job and store the file. See
[Deploy and operate]($docs.deployment) for timeouts, caching, and queues.
