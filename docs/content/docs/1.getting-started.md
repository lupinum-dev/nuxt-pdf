Nuxt PDF turns Vue components into PDFs on a Nuxt server. Put a typed Vue
template in `pdfs/`, pass it data from a Nitro route, and return the completed
PDF response.

To try it before you install anything, edit a template in the
[playground]($page.playground). It renders the PDF in your browser as you type.

Use Nuxt PDF when you control a structured, data-driven document:

- invoices, quotes, and receipts;
- reports and statements;
- certificates, tickets, and labels.

The package provides PDF layout primitives, local images and fonts, SVG
graphics, links, bookmarks, tables of contents, development previews, and test
helpers. Templates run on Node and stay out of the browser bundle.

It also writes these document features:

- [rich text]($docs.rich-text) from CMS editor HTML or Markdown;
- [fillable forms]($docs.forms) with text fields, checkboxes, radio groups and
  drop-down lists;
- [e-invoices]($docs.e-invoices) (ZUGFeRD, Factur-X and XRechnung) from
  invoice data;
- [PDF/A-3b and Factur-X]($docs.pdf-a-and-factur-x) files;
- [accessible tagged PDF]($docs.accessible-pdf) for PDF/UA-1 and PDF/A-3a;
- [password protection]($docs.protection) with AES-256.

## Pick the right rendering tool

Pick a different tool when:

- **You want to print an existing web page.** Use headless Chromium through
  Playwright or Puppeteer. Nuxt PDF does not compile HTML or browser CSS.
  `PdfRichText` prints the formatted text of a CMS editor (headings, lists,
  links); it does not lay out a web page.
- **You want to display an existing PDF.** Use
  [PDF.js](https://mozilla.github.io/pdf.js/). Nuxt PDF creates files; it is not
  a viewer.
- **You want to edit, merge, fill, or sign an existing PDF.** Use
  [pdf-lib](https://pdf-lib.js.org/) or a signing service. Nuxt PDF creates new
  documents from application data.

## Current scope

Nuxt PDF follows semantic versioning: a breaking change comes only in a new
major version, with a migration note in the changelog.

The current release does not include a web page compiler, browser CSS, a
chart engine, digital signatures, browser rendering, or edge rendering.
Templates style with a subset of CSS in a `<style>` block. Nuxt PDF does not
promise byte-identical output across machines.

The [supported behavior]($docs.supported-behavior) page summarizes the
tested boundary. The repository's
[CONFORMANCE.md](https://github.com/lupinum-dev/nuxt-pdf/blob/main/CONFORMANCE.md)
contains the full list of tested behavior.
