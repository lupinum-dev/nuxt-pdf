Nuxt PDF is a Nuxt module. It does not require a separate service or CLI.

## Check the requirements

| Layer | Supported versions |
| --- | --- |
| Node.js | `^22.14.0`, `^24.0.0`, or `^26.0.0` |
| Nuxt | `^4.4.8` |
| Vue | `^3.5.0` |

Nuxt 3, Node 20, browser rendering, and edge rendering are outside the current
support boundary.

## Add the module

Start in the folder of your Nuxt 4 application. If you do not have one yet,
create it first, as the
[Nuxt installation guide](https://nuxt.com/docs/getting-started/installation)
describes.

Install the package:

```bash [Terminal]
pnpm add @lupinum/nuxt-pdf
```

::info{icon="lucide:package"}
pnpm 11 runs the build scripts of dependencies only after you approve them,
and an install can stop with `ERR_PNPM_IGNORED_BUILDS` for `esbuild`. Nuxt PDF
does not need that script: esbuild gets its program from a platform package.
To skip the script without the error, add it to `pnpm-workspace.yaml`:

```text [pnpm-workspace.yaml]
allowBuilds:
  esbuild: false
```
::

Add it to `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-pdf'],
})
```

The module now discovers Vue templates under `pdfs/`, generates the typed
server-only `#pdf` registry, and adds the `/_pdf` development preview.

::info{icon="lucide:info"}
If your editor does not recognize `#pdf` after installation, run
`pnpm nuxt prepare` once. Nuxt also refreshes the generated types when the
development server starts.
::

### Set up your coding agent

Nuxt PDF ships its documentation inside the package, so coding agents read the
pages that match the installed version. Give your coding agent this task:

```text
Set up @lupinum/nuxt-pdf for coding agents as described under "Agent setup" in its README.
```

Continue with [Render your first PDF]($docs.quickstart).

## Add test dependencies later

The optional test entry needs `pdfjs-dist` to read PDFs and `@napi-rs/canvas`
for pdf.js and for raster comparisons. `parsePdf` fails without either package.
Install both when you start testing PDF output:

```bash [Terminal]
pnpm add -D pdfjs-dist @napi-rs/canvas
```

The [testing guide]($docs.testing) shows the complete workflow.
