---
title: Page sizes
description: Named and custom page dimensions accepted by PdfPage.
icon: lucide:file
---

Set `PdfPage.size` to an uppercase named size or to explicit dimensions. The
default is `A4`.

```vue
<PdfPage size="LETTER">
  <PdfText>Letter page</PdfText>
</PdfPage>
```

Page-size names are case-sensitive:

| Family | Accepted names |
| --- | --- |
| ISO A | `4A0`, `2A0`, `A0`, `A1`, `A2`, `A3`, `A4`, `A5`, `A6`, `A7`, `A8`, `A9`, `A10` |
| ISO B | `B0`, `B1`, `B2`, `B3`, `B4`, `B5`, `B6`, `B7`, `B8`, `B9`, `B10` |
| ISO C | `C0`, `C1`, `C2`, `C3`, `C4`, `C5`, `C6`, `C7`, `C8`, `C9`, `C10` |
| Raw format | `RA0`, `RA1`, `RA2`, `RA3`, `RA4` |
| Supplementary raw format | `SRA0`, `SRA1`, `SRA2`, `SRA3`, `SRA4` |
| North American and other | `EXECUTIVE`, `FOLIO`, `LEGAL`, `LETTER`, `TABLOID`, `ID1` |

## Custom dimensions

Use a two-value tuple or a width/height object. A unitless number is a PDF
point. String dimensions accept `pt`, `in`, `mm`, `cm`, or `px`:

```vue
<PdfPage :size="['210mm', '297mm']">
  <PdfText>Custom A4 dimensions</PdfText>
</PdfPage>
```

```vue
<PdfPage :size="{ width: '4in', height: '6in' }">
  <PdfText>Shipping label</PdfText>
</PdfPage>
```

`px` uses the page's `dpi` prop. The default DPI is `72`. Use `orientation` to
swap portrait and landscape dimensions without reversing the size tuple.
